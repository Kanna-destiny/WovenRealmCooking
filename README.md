# 织境空间·料理扩展

《织境空间》的独立料理附属 Mod，为《Degrees of Lewdity》增加 AI 辅助菜谱、快速制作、精致料理、即兴料理，以及原创料理道具与 NPC 共同品尝剧情。

可根据目标料理或现有食材设计菜谱，逐步控制配料、火候和技法，也能自由组合背包材料。成品收入织境料理道具，支持自己食用、赠送和多人共同品尝，并保存评价与改良建议。菜谱、料理过程和成品记录跟随游戏存档恢复。

AI 负责菜谱创意、味道描述和剧情反应；材料消耗、游戏时间、品质和人物效果由系统校验并结算。AI 调用由玩家主动触发，接口配置复用织境空间主 Mod。

先加载织境空间主 Mod v0.1.550 或更高版本，再加载料理扩展。从原版厨房选项后的“织境厨房”进入，或通过“料理”入口使用成品。
